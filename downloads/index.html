Download Sonixy

Sonixy is a free Android music player and downloader. Sonixy Connect is the companion app for playing your phone's audio through a Windows PC or Mac.

Official source: Get installers from the Sonixy GitHub Releases page. Avoid unofficial mirrors. Compare the download's SHA-256 checksum with the value in the project README when a checksum is published.

System requirements

  • Android: Android 7.0 or later (APK installation).
  • Windows: Windows 10 or 11 for Sonixy Connect.
  • macOS: macOS 12 or later for Sonixy Connect; the project lists Intel and Apple silicon support.

Requirements and available installers can change. Check the current release page and its notes before installing.

Install Sonixy on Android

  1. Open the official releases and download the latest Android APK.
  2. Open the downloaded APK. If Android asks, allow your browser or file manager to install unknown apps.
  3. Review Android's requested permissions and install only if you trust the source.
  4. For extra verification, compare the file's SHA-256 with the checksum in the README.

Install Sonixy Connect on Windows

  1. Download the Windows installer from the official releases.
  2. Run the installer and follow Windows prompts. Review any permission request before accepting it.
  3. Open Sonixy on your Android device, use its Connect/cast feature, and follow the pairing prompt on your PC.

Install Sonixy Connect on Mac

  1. Download the macOS disk image from the official releases.
  2. Open the disk image and move Sonixy Connect to Applications.
  3. The project README notes that its Mac app may not be notarized. macOS may require you to review the warning in Privacy & Security before opening it. Proceed only if you trust the download and publisher.
  4. Pair with Sonixy on Android over your local network.

Frequently asked questions

Is Sonixy free?

The project describes Sonixy as free to download and use. See the license for the terms.

Where can I safely get the installer?

Use only the official GitHub Releases page or links from the official Sonixy website. The README lists checksums for supported releases.

Does Sonixy work with Spotify and other services?

The project lists links from Spotify and several other music and media services among supported sources. Support can change; consult the current supported sources and release notes.

Is Sonixy affiliated with Spotify or other services?

No. Sonixy is an independent project. Respect copyright and each service's terms, and only download content you are authorized to use.

Is Sonixy open source?

The project describes the application as closed source freeware. See the repository's LICENSE.
