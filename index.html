Core Capabilities

Built for Pure Audio Freedom

Spotify Link Resolver

Paste any Spotify track, album, playlist, or artist link. Sonixy extracts complete metadata, high-resolution album artwork, and high-fidelity audio streams in seconds.

Real-Time Synced Lyrics

Enjoy live, syllable-precise karaoke lyrics. Missing lyrics? The built-in Lyrics Search Engine scans and saves sidecar `.lrc` files automatically.

Ultra-Smooth 60fps UI

Rebuilt with decoupled Jetpack Compose architecture and hardware graphics transforms. Zero jank, zero dropped frames, and instant player overlay open/close response.

Ambient Desktop Player

Immerse yourself on Windows with clean typography, lyric sidebar, hotkey controls, and automatic background updates from GitHub.

Automotive & Drive Mode

Large tactile buttons and swipe gestures designed for in-car dashboard mounts and distraction-free road trips.

100% Offline & Private

No telemetry, no tracking, no mandatory cloud accounts. You own your music files directly on your device storage forever.

Quick Installation

Get Started in Seconds

Android Setup

  • 1 Click the Download APK button to save the signed package.
  • 2 Tap the downloaded `.apk` file and allow Install unknown apps if prompted.
  • 3 Open Sonixy, paste your first Spotify playlist link, and enjoy!

Windows Setup

  • 1 Click the Download .exe button to get the installer.
  • 2 Run Sonixy-Desktop-Setup-1.2.6.exe. Setup completes automatically.
  • 3 Launch Sonixy from your Desktop or Start Menu. Future updates apply in background!
